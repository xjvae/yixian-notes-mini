页头图 150×57 一比一

从 便签软件界面图生成需求.png 里取字标那一条（源图 x71 y60 821×312），产品名和那句 slogan 全在，笔记本和它的黑边一点没进来。 页头图不会被缩放，所以这 22px 高的字标在装出来的窗口里就是这里的样子。 MUI2 默认把页头图画在左上，右上那一版要在 hooks.nsh 里 !define MUI_HEADERIMAGE_RIGHT （它是全局开关，Interface.nsh 里只 !ifdef、从不 !undef，定义一次六个页都跟着走）。

左幅 164×314，右边是它被压到 268 高之后

一处换不掉，先说清。 模板只把 SIDEBARIMAGE 接到 MUI_WELCOMEFINISHPAGE_BITMAP，没有 MUI_UNWELCOMEFINISHPAGE_BITMAP 的入口。 所以卸载页的左幅仍是 NSIS 默认那张（上面第 6 页画的就是它本来的样子）。 要连它一起换，得自己维护 nsis.template（一份 30 KB 的 installer.nsi，此后每次升 Tauri 都要跟）。 我的建议是先接受：卸载是极少走到的一页，而那页真正要紧的那句警告， 改语言文件就够了。

要覆盖的中文

两条路，都装出来核对过：页面正文与标题走 hooks.nsh 里的 MUI2 !define；页眉那两行（标题 + 副标题）和 tauri 自己的提示句走 nsis/SimpChinese.nsh 重定义 LangString。后者实测有效：页眉从"许可证协议"变成了"许可协议"，因为这份文件是在 !insertmacro MUI_LANGUAGE 之后 !include 的。

实际落地的配置

{
  "bundle": {
    "licenseFile": "../LICENSE.zh-CN.txt",        // 中文译文；英文原件 LICENSE 一个字没动
    "windows": {
      "nsis": {
        "languages": ["SimpChinese"],             // 只中文；语言包本机已带，不联网
        "installerIcon": "icons/icon.ico",
        "uninstallerIcon": "icons/icon.ico",
        "headerImage": "icons/installer-header.bmp",   // 150×57 24bit BMP
        "sidebarImage": "icons/installer-sidebar.bmp",  // 164×314 24bit BMP
        "installerHooks": "nsis/hooks.nsh",       // 页标题与正文的中文覆盖
        "customLanguageFiles": { "SimpChinese": "nsis/SimpChinese.nsh" }
      }
    }
  }
}
// startMenuFolder 故意不设：模板是 !if "${STARTMENUFOLDER}" != "" 才插那一页，留空走 Skip
// installMode 默认就是 currentUser：装到自己账户下，不弹 UAC

两份 .nsh 的分工是实测出来的，不是猜的：模板在顶部（各页宏之前）!include installerHooks，所以页面文案用 !define MUI_WELCOMEPAGE_TEXT 这一类 MUI2 入口；而在所有 !insertmacro MUI_LANGUAGE 之后才 !include 语言文件，且这份会顶掉 tauri 自带的那份。所以 nsis/SimpChinese.nsh 里 27 条 LangString 一条都不能少， 少一条 makensis 就在 $(deleteAppData) 那种引用处断掉。 两个文件都必须是 UTF-8 带 BOM，否则中文在 NSIS 里是乱码。

三条都按你定的做了：左幅整张缩放不裁、右下角水印抹平、协议正文换成中文译文（英文原件 LICENSE 一个字没动）。两个 BMP 进了 src-tauri/icons/，配置改成上面那份，两份 .nsh 写在 src-tauri/nsis/，版本三处手改成 1.2.5，包打出来了：src-tauri\target\release\bundle\nsis\YixianNotesMini_1.2.5_x64-setup.exe，2.03 MiB，makensis 零警告。 装出来核对过的：欢迎页（左幅 + 中文正文）、协议页（中文正文不糊、页眉"许可协议 / 安装前请过一眼"、页头图在右上）、位置页（页眉 + 正文 + 那格"安装位置"）。走到位置页点取消，什么都没装：%LOCALAPPDATA%\YixianNotesMini 至今不存在。没核对到的：进度页、完成页、"已经装过"那页、卸载页，这四页要真装一次才看得见。还有一处我在捕获图里判不准：欢迎页正文第二段每行中间像被划了一道，换行写法改成 $\r$\n 之后一模一样，所以分不清是 8pt 中文回退字体真这么画，还是抓帧的锅。 你自己开包看一眼最快，走到欢迎页就能看见。
